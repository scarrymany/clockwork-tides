# Clockwork Tides — установка

Мод добавляет три удочки в стиле Create: андезитовую, медную с патиной и латунную. У каждой своя дополнительная добыча; обычный ванильный улов сохраняется.

## Версии

- Minecraft Java **1.21.1**, лицензионная установка
- Java **21**
- NeoForge **21.1.219**
- Create **6.0.10**
- Clockwork Tides **1.0.0**

## Быстрый старт

Самый простой вариант: импортируйте `.mrpack` из архива в Prism Launcher или Modrinth App. Лаунчер загрузит официальные Create и NeoForge. Для запуска нужен ваш лицензионный аккаунт Minecraft.

Ручная установка:

1. Установите NeoForge в отдельный профиль Minecraft 1.21.1
2. Скачайте [официальный Create 6.0.10](https://modrinth.com/mod/create/version/UjX6dr61)
3. Положите Create и `clockwork-tides-1.0.0.jar` в папку `mods` этого профиля
4. Для игры на сервере установите одинаковые версии на сервер и всем игрокам

Ponder, Flywheel и Registrate уже включены в полный официальный JAR Create. Отдельно ставить их не нужно. Версии Forge/Fabric не подходят.

Архив включает наш мод, инструкции и загрузчики официального Create с проверкой SHA-256. Сам Create не переопубликован в архиве из-за ограничений на его ресурсы. В Windows можно выполнить `tools/fetch-create.ps1 -ModsDirectory 'путь\к\mods'`; с Python — `python tools/fetch-create.py путь/к/mods`.

## Как ловить

[Крафты и схемы](RECIPES.md) · [Шансы, добыча и настройки](MECHANICS.md)

Рыбачьте как обычной удочкой. Дополнительный улов возможен только при успешной ловле на открытой воде. Раннее сматывание и зацеп существа не дают бонуса.

Андезитовая удочка: 192 прочности, простые материалы. Медная: 256 прочности, дополнительная рыба. Латунная: 384 прочности, мелкие детали Create.

Зачарования применяются как к ванильной удочке. Ремонт в наковальне: андезитовый сплав, медный слиток и латунный слиток соответственно. ВАЖНО: крафт следующей ступени расходует прежнюю удочку и сбрасывает её имя/зачарования. Сначала изготовьте нужную ступень, затем зачаровывайте.
